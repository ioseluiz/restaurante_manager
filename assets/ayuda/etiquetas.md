# Etiquetas y Códigos

Administra los **códigos de barras / QR** de los insumos y **imprime etiquetas** para identificar productos en bodega y cocina. Los códigos permiten **escanear** en la [Toma de Inventario](ayuda:conteo) y al recibir compras.

## Dos tipos de código

- **Código del fabricante**: el que ya trae el producto. Debe asociarse a una **presentación** concreta (la caja, el saco…), porque el fabricante identifica el empaque.
- **Código interno**: uno que genera el sistema. Puede asociarse a la **unidad base** del insumo, útil para productos de **peso variable** (carne, quesos) que se etiquetan por porción.

## Tareas comunes

| Quiero… | Botón |
|---|---|
| Registrar el código de un producto con el escáner | **Registrar por Escaneo** |
| Crear un código propio para un insumo | **Generar Código Interno** |
| Ver o borrar los códigos de un insumo | **Ver / Eliminar Códigos** (**Eliminar Código Seleccionado**) |
| Imprimir etiquetas | **Imprimir Etiqueta(s)** / **Generar PDF e Imprimir** |

## Pasos para etiquetar

1. Elija el insumo (y la presentación, si corresponde).
2. Genere o registre el código.
3. Indique cuántas etiquetas necesita y pulse **Generar e Imprimir**: se crea un PDF listo para imprimir.

## Antes de empezar

Los insumos y sus presentaciones deben existir en el [Catálogo de Insumos](ayuda:insumos). También puede llegar aquí desde el botón **Códigos de barras / QR…** de ese módulo.

## Consejos

- Un mismo código no puede pertenecer a dos insumos: si el escáner avisa que ya existe, revise a qué insumo está vinculado.
- Para escanear, haga clic en el campo «Escanee o escriba el código…» y use el lector (o escriba el código a mano).
