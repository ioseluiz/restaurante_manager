# Unidades de Medida

Lista de las **unidades** que usa el sistema para medir los insumos: gramo, kilogramo, libra, mililitro, litro, unidad, etc. Es lo primero que se configura.

## Tareas

| Quiero… | Cómo |
|---|---|
| Agregar una unidad | **+ Nueva Unidad**: nombre y **abreviatura** (g, kg, lb, ml, l, u…) → **Guardar** |
| Corregir una unidad | Seleccione la fila → **Editar Seleccionada** |
| Quitar una unidad | Seleccione la fila → **Eliminar** |

## Para qué se usan

- Cada **insumo** tiene una **unidad base** ([Catálogo de Insumos](ayuda:insumos)).
- Las **recetas** se escriben en la unidad base del insumo ([Recetas](ayuda:recetas)).
- El programa **no tiene una pantalla de conversiones**. Solo [Costo de Platos](ayuda:costo_platos) y su importador convierten entre unidades de la misma familia (g/kg/lb/oz y ml/l/gal), y únicamente **si las abreviaturas coinciden** con esas: use estas abreviaturas.

## Consejos

- Use abreviaturas cortas y consistentes; no cree «Gramo» y «Gramos» por separado.
- **No elimine** una unidad que ya usan insumos o recetas.
- Piense la unidad base del insumo como **la más pequeña** con la que se mide en cocina (gramos en vez de libras).
